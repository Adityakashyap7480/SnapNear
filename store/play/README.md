# Google Play Store listing assets

Drop the final graphics here before submitting. Play Console needs these files — they are not generated by the app build.

## Required

| File | Spec | Notes |
|------|------|--------|
| `feature-graphic.png` | 1024 × 500 | Store banner (no rounded corners needed) |
| `phone-1.png` … | min 2 screenshots | Phone UI — login, book, partner list, payment |
| `icon-512.png` | 512 × 512 | Can export from `app/assets/icon.png` |

## Recommended screenshots (portrait)

1. Home / book a shoot  
2. Photographer match nearby  
3. Booking confirmation  
4. UPI / Razorpay payment  
5. Partner go-online (optional second listing set)

Use a real Android device or emulator at ~1080×1920. Do not include personal data of real customers.
